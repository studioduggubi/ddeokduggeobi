# 떡두꺼비 작명소

스튜디오두꺼비의 가족 사주·출산 후보일·이름 비교 사이트입니다.

공개 사이트: https://studioduggubi.github.io/ddeokduggeobi/

이 저장소는 GitHub Pages 정적 배포 파일을 보관합니다. `main` 브랜치의 `/docs` 폴더를 게시합니다.

- 방문자는 로그인 없이 이용합니다.
- 사주 계산·가족 비교·출산 일시별 후보·개인 리포트는 브라우저에서 동작합니다.
- 생년월일을 서버로 전송하거나 저장하지 않습니다.
- 이름 통계는 2026-11-07 수집 자료 20건이며, 미수집 이름·최신 통계는 네임차트 원문으로 연결합니다.
- 지원 범위와 전통 해석의 한계는 사이트 안의 계산 기준을 확인하세요.
- `docs/reference-report.pdf`: 레퍼런스 10개 서비스 분석·설계 리포트
- `docs/validation.json`: 실제 역법 검증 결과

편집 원본과 원자료·검수 기록은 Duggubi-Workspace의 baby-saju-naming 프로젝트 폴더에 보관합니다.
