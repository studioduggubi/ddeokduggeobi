# 떡두꺼비 작명소

공개 사이트: https://studioduggubi.github.io/ddeokduggeobi/

스튜디오두꺼비의 채팅형 아기 작명 상담입니다. Montage 4.2.0 UI를 사용합니다.

- 최대 20개 후보를 카드·여러 이름 붙여넣기·채팅으로 입력하고 같은 브라우저에 이름만 보관합니다.
- 필요한 정보를 차례로 묻고, 성씨·소리 인상·가족이 담고 싶은 뜻·선택한 부모 정보·실제 출생시각으로 후보를 브리핑합니다.
- 후보별 참고 점수·근거, 두 이름 비교, 연결 이유가 있는 추가 후보, 개인 인쇄/PDF 리포트를 제공합니다.
- 점수는 공개한 편집 기준이며 확인 범위와 잠정 여부를 표시합니다. 전통 효능·종합 용신·발음 난이도 실험의 검증 점수가 아닙니다.
- 외부 LLM API를 연결하지 않은 안내형 채팅입니다. 이름·성씨·양력 날짜·오전/오후 시간·취향·부모 정보에 맞는 기본 입력을 처리합니다.
- 생년월일과 대화는 저장하거나 서버로 전송하지 않습니다. 방문자 로그인은 없습니다.
- 이름 통계는 2026-11-07 수집한 20개 이름 기준이며 미수집 이름·최신 통계는 원문 확인이 필요합니다.

명식 계산 범위·시간 기준·전통 해석 한계는 사이트에서 확인하세요.

- docs/scoring-standard.json: 공개 점수 기준
- docs/reference-report.pdf: 작명·사주 서비스 10곳 분석
- docs/validation.json: 역법 검증 결과
- docs/third-party-notices.txt: Montage 라이선스 고지

main 브랜치의 docs 폴더를 GitHub Pages로 게시합니다. 편집 원본·원자료·검수 기록은 Duggubi-Workspace의 baby-saju-naming 프로젝트에 보관합니다.
